Project Information

An academic prototype from Ho Chi Minh City University of Technology and Education (HCM-UTE).

Overview

MediCare helps manage medication schedules. It recognizes the user’s face with a HuskyLens K210 camera, checks the schedule, and opens the matching compartment gate with a servo so the medicine slides down to the tray. An administrator registers users, assigns Face IDs, compartments and dose times through a web page.

How it works

  1. The administrator creates a profile, assigns a Face ID, a compartment and a schedule.
  2. The user stands in front of the HuskyLens camera.
  3. The camera returns an ID, which the system compares with the registered list.
  4. The system checks: right time, right person, right medicine, right conditions.
  5. The LCD shows the name for about 3 seconds, then “PLEASE TAKE MEDS”; the servo opens the compartment gate.
  6. LED and buzzer signal for about 10 seconds; the dose is logged to prevent duplicate dispensing.

Key features

  • Register and manage users and Face IDs.
  • Schedule by person, compartment and dose time.
  • Recognize the user before checking dispensing conditions.
  • Audible alarm for unknown faces.
  • Monitor temperature (> 30 °C) and humidity (> 75 %).

Limitations and safety

  • It cannot identify the name, ingredients or dose of a medicine.
  • It cannot confirm that the user actually took the medicine.
  • It does not replace a caregiver or a doctor’s advice.

MediCare is an educational prototype, not a certified medical device. Medicine must be prepared by a responsible person and loaded into the correct compartment.

Materials and mechanics

  • Cardboard: box body, partitions, panels.
  • Foam: shaping, compartment separation, fixing components.
  • Glue for panels and mechanical parts.
  • Upper box: 6 compartments, camera, LCD, electronics bay.
  • Sloped chute at the bottom of the upper box, and a collection tray in the lower box.

System architecture

  • Interface: web page for users, Face IDs, compartments and schedules.
  • Communication: ESP8266 (Wi-Fi).
  • Processing: Arduino Mega 2560.
  • Recognition: HuskyLens K210.
  • Actuation: 6 SG90 servos.
  • Display and monitoring: LCD, DHT11, LED, buzzer.

Data flow: Web page ↔ ESP8266 ↔ Arduino Mega ↔ HuskyLens, servos, LCD, DHT11, LED, buzzer.

User Guide

How to use the device and the management web page.

Using the management web page

  1. Power the machine, then connect a laptop or phone to the Wi-Fi network MediCare-Setup (default password SmartMed2026).
  2. Open a browser and go to http://192.168.4.1.
  3. In Connect dispenser, press Connect Wi-Fi (ESP8266). A USB cable can be used instead.
  4. In Patients, add the name, age and Face ID (it must match the ID learned on the HuskyLens).
  5. In Medicines, create a medicine and assign it to compartment 1 to 6.
  6. In Schedules, choose the patient, medicine, time window, start date, end date and dose.
  7. Keep the web page open during use: when the machine recognizes a face, the web page checks the schedule and commands the machine to dispense.
  8. Check status, temperature, humidity and the dispensing log on the Dashboard.

Using the device

  1. A responsible person checks the medicine against the prescription, opens the upper lid and loads each compartment correctly.
  2. Set the schedule on the web page according to the confirmed plan.
  3. At dose time, stand in front of the camera on the front panel (marked “Look here”).
  4. Wait for the LCD to confirm: it shows the name for about 3 seconds, then “PLEASE TAKE MEDS”.
  5. Take the medicine from the tray below. Keep hands away from the gates and servos.
  6. If recognition fails, nothing dispenses or the buzzer sounds unusually, tell the administrator and do not open the machine yourself.

Areas of the web page

  • Dashboard: connection, users, schedules, status of the 6 compartments, temperature, humidity.
  • Patients: name, age, Face ID.
  • Schedules: person, compartment, time window, dose.
  • Compartments: the 6 compartments and related schedules.
  • Environment: temperature, humidity, alerts.
  • Log: time, user, compartment opened.

Future development

  • Improve the registration and scheduling interface.
  • Make web-to-machine communication more reliable.
  • Improve gate motion to reduce medicine jams.
  • Send remote notifications to administrators.
  • Improve the enclosure, tray, dust and moisture protection.
  • Run repeated tests to assess durability and safety.
